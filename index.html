01

Encryption is a machine state

The same letter does not always produce the same output because the rotors move. The key is not just the wiring—it is the starting state.

02

Brute force is organized guessing

A computer can try AAA, AAB, AAC… then decrypt each candidate and score it against one or many known words supplied by the player.

03

Keyspace creates friction

This game only brute-forces 26³ rotor starts. Real wartime Enigma also involved rotor order, rings, plugboard settings, procedure mistakes, and cribs.
